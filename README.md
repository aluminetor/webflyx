## 📖 Descripción

Webflyx es un proyecto educativo desarrollado como parte del curso **Learn Git** de Boot.dev, cuyo propósito es fortalecer los conocimientos sobre el control de versiones y la gestión de repositorios de software.

## 🎯 Objetivos de aprendizaje

- Gestionar repositorios locales y remotos.
- Crear y administrar ramas (branches).
- Realizar commits y consultar el historial de cambios.
- Comprender el funcionamiento de Merge y Rebase.
- Resolver conflictos de integración.
- Aplicar buenas prácticas de control de versiones.

## 🛠️ Tecnologías y herramientas

- Git
- GitHub
- Terminal (CLI)
